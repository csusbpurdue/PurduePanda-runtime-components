# My Local Repository with Runtime Components

This project sets up all preferred settings for all of my Runtime Components and is uploaded here on Github for easy access. This repository has been created to make it as easy as possible to set up settings when using a new machine or any other related case.

## Files Included

* **.bashrc** - Runtime Component read by bash every time you open a terminal
* **.zshrc** - Runtime Component read by zsh, the default shell in Mac, every time you open a terminal
* **.vimrc** - Runtime Component read by vim every time it opens
* **.gitconfig** - Configuration read by git every time you run
* **.gdbinit** - Runtime Component read by gdb every time you start a debugger

## How to Install

Follow these steps to get these files into your local computer:

### 1. Copy the files from this repository onto your local system.
### 2. Grant access to execute the script using "chmod +x install.sh".
### 3. Execute the script to initialize your runtime components by doing "./install.sh".
